# Python for Django

Practical Python examples and exercises designed to prepare
students for Django development.

## Part 1 — Python Basics

- Variables and Data Types
- Strings
- Lists
- Dictionaries
- Conditions
- Loops

## Part 2 — Functions

- Defining Functions
- Parameters
- Return Values
- *args and **kwargs
- Practical Exercises

## Part 3 — Python Concepts Needed for Django

- Modules and Imports
- Classes and Objects
- Exceptions
- Virtual Environments
- pip

## Part 4 — Connecting Python to Django

The goal is to understand how Python concepts appear in Django.

| Python | Django |
|---|---|
| Dictionary | Request / Context Data |
| Function | Views |
| Class | Models / Forms / Class-Based Views |
| Module | Django Apps / Files |
| Exception | Error Handling |
| Package | Django / Third-Party Packages |
| Virtual Environment | Isolated Project Environment |
| pip | Dependency Management |
